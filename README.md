# CLI Quiz System

A simple **command-line quiz application with a point-based scoring system**, built with **TypeScript and Node.js**.

This project was developed during my time at **PIAIC (Presidential Initiative for Artificial Intelligence and Computing)** as part of my early experimentation with building, packaging, and publishing **TypeScript-based CLI applications as npm packages**.

## About

CLI Quiz System is an interactive terminal-based quiz application where users answer a series of questions and receive points based on their answers.

The project was created as a practical exercise for learning TypeScript, handling user input, implementing quiz logic, and building an interactive command-line experience.

## Features

* Interactive quiz gameplay
* Multiple-choice questions
* Point-based scoring system
* Interactive command-line prompts
* Question management through a separate questions module
* Styled terminal output
* Loading animations
* Runs directly through `npx`

## Usage

The published package can be run directly using:

```bash
npx adil-quiz
```
